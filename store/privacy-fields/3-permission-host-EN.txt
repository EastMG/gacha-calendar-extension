[Host permissions, 81 entries]

The extension fetches public banner/event info from game announcement pages and community wikis; browsers require declaring those domains before cross-origin requests.

1) No <all_urls>. 80 of 81 are specific domains; one subdomain wildcard: https://*.gamekee.com/* (plus https://gamekee.com/*).
2) Needed because GameKee's content CDN is issued by its API (content_cdn -> api-cdn.gamekee.com), so it cannot be pre-listed.
3) Covers 61 games' official pages and wikis (Bwiki, PRTS, FZ Wiki, GameKee, GameTora, wikiwiki, Game8, miHoYo endpoints): Genshin Impact, Honkai: Star Rail, Zenless Zone Zero, Arknights, Blue Archive and more.
4) sekai-world.github.io / raw.githubusercontent.com hold the Project SEKAI wiki dataset; gh-proxy.com is its read-only mirror.
5) Some hosts load only icons: is1-ssl.mzstatic.com, storage.moegirl.org.cn, bannerhistory.app; unavatar.io only for the Kantai Collection avatar.
6) Read-only; no user data sent; no content script.

[DNR: declarativeNetRequestWithHostAccess]

Only adds a Referer header for GameKee's CDN (which checks it and fetch cannot set it). Matches only api-cdn.gamekee.com, changes only a request header, reads/uploads nothing. The all-sites declarativeNetRequest variant is NOT requested.
