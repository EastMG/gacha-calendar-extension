本扩展的功能是抓取各游戏官方公告页与社区 Wiki 上的公开活动/卡池信息，因此需要访问这些来源站。浏览器要求扩展在发起跨域请求前静态声明目标域名，所以这些域名逐个列在 manifest 中。

需要说明的关键点：
1) 未申请 <all_urls>，也没有任何通配的全网访问权限，只声明了实际抓取用到的具体域名；
2) 这些域名对应的是原神、崩坏：星穹铁道、绝区零、明日方舟、蔚蓝档案、赛马娘、Fate/Grand Order 等游戏的官方公告页与社区 Wiki（Bwiki / PRTS / FZ Wiki / GameKee / GameTora 等）；
3) 其中 `sekai-world.github.io` / `raw.githubusercontent.com` 是「世界计划」社区 Wiki 的静态数据源（托管于 GitHub Pages），`gh-proxy.com` 是该社区提供的只读镜像代理 —— 因为 GitHub Pages 不返回跨域头，扩展必须经该镜像才能读到同一份公开数据；二者读的都是同一个开源数据集；
4) 请求仅用于读取公开页面内容，不向这些站点发送任何用户数据；
5) 本扩展不包含 content script，因此不会读取或修改用户正在浏览的任何网页内容。
