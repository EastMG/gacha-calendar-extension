Used only to store two kinds of information locally on the user's own device: (1) user preferences — which entries to display, their order, the chosen banner/event sources, the refresh interval, and any custom source URL the user types in; and (2) a cache of the most recent successful fetch, used to keep showing the previous data when a source rate-limits or the network fails. This data is written only to chrome.storage.local. It is never synced, never uploaded, and contains no personally identifiable information.
