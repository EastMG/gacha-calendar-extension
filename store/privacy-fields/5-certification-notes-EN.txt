This extension requires no sign-in and no account, so it can be fully tested right after installation.

Testing steps:
1. After installing, click the "二游日历" (Gacha Calendar) icon in the toolbar. The panel appears immediately and automatically starts one fetch round (about 5-15 seconds).
2. Each game shows two lines: the current banner (with featured characters) and the current event, plus remaining-time countdowns.
3. Hover over the banner/event text to see the full banner name, featured characters and original date text.
4. Click the gear icon at the top right of the panel to open the settings page, where you can toggle each game on/off, reorder entries, delete and restore entries, and switch fetch sources. The "开始自检" (Run self-check) button at the bottom of the settings page runs every source once and reports the result.

Things worth knowing:
- Some source sites rate-limit requests. If you refresh repeatedly in a short time, Bwiki returns HTTP 567; the panel then marks that source as failed and keeps showing the previous successful data for that column. This is not an extension defect and recovers by itself after a while.
- For a few games, when no new banner/event has been published yet in the current period, the panel shows "未公布" (not announced) or "无匹配" (no match). This is expected.
- The extension collects no data, uploads nothing, and contains no content script, so it never modifies any web page.
