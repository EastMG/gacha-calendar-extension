This extension requires no sign-in and no account, so it can be fully tested right after installation.

Testing steps:
1. After installing, click the "二游日历" (Gacha Calendar) icon in the toolbar. A schedule panel opens directly (520x600) and one fetch round starts automatically in the background (about 5-15 seconds).
2. The overview at the top shows "N items within 24 hours - N within 7 days" plus a date pill. Below it is a "recent card": the most urgent item (icon / days left / date range / progress bar) with the next items listed beside it. You can switch it to a "recent list" in the settings page.
3. Below that is the schedule table: each game takes two lines - the current banner on the first, the current event on the second - each with its date range, remaining time and a 14-day progress bar. Hover over the banner/event text to see the full banner name, featured characters and original date text.
4. In the panel footer, from left to right: fetch status, "last updated" time, refresh (⟳) and settings (⚙). Clicking the gear opens the settings page in a new tab.
5. The number badge on the toolbar icon counts items expiring within 3 days (can be turned off in the settings page).
6. The settings page can also be opened from "Extension options" for this extension on edge://extensions. There you can toggle each game's visibility, switch banner/event sources, pick a custom accent color per entry, reorder entries, delete and restore entries. The "开始自检" (Run self-check) button at the bottom runs every source once and reports the result.
7. Expiry reminders: enabled by default, with 72 / 24 / 6 / 2 hour thresholds. Clicking "发送测试通知" (Send test notification) in the settings page immediately shows one system notification, which confirms the notification path works. The "提醒" (remind) column in the entries table is checked by default; unchecking it stops notifications for that entry. Note: the OS must not be in "Do Not Disturb" mode, and reminders do not fire while the browser is fully closed (the extension has no resident process).
8. Calendar export: in the settings page, "导出日历 -> 导出 .ics" exports the currently active banners and events as a calendar file that can be imported into phone or desktop calendars.
9. The refresh timing defaults to "on browser startup" and can be changed to an interval of 1-42 days. To go back to the older compact popup: Settings -> Experimental -> uncheck "新日程面板" (new schedule panel).

Things worth knowing:
- 61 games are covered; 52 are shown by default. The other 9 are hidden by default because at least one of their two sources is not configured yet, and can be enabled via the "展示" (show) checkbox in the settings page.
- Some source sites rate-limit requests. If you refresh repeatedly in a short time, Bwiki returns HTTP 567; the panel footer then tells you which source failed and why, and that column keeps showing the previous successful data. This is not an extension defect and recovers by itself after a while.
- For a few games, when no new banner/event has been published yet in the current period, the panel shows "未公布" (not announced) or "无匹配" (no match). This is expected.
- The extension collects no data, uploads nothing, and contains no content script, so it never modifies any web page.
