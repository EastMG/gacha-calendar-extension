## 二、说明（每种语言必填，250 ~ 10000 字符）

当前字数：654 字符（下限 250，上限 10000）。

```
「二游日历」把 28 款二次元手游当前正在进行的卡池与活动排期，收在一处看。

点浏览器工具栏图标，每款游戏显示两行：当期卡池（外显 UP 角色）与当期活动，各带「还剩 X 天 X 小时 X 分钟」的倒计时。鼠标悬停可以看完整的卡池名称、UP 角色列表和时间原文。

覆盖 28 款：原神、崩坏：星穹铁道、绝区零、崩坏3、鸣潮、明日方舟、明日方舟：终末地、蔚蓝档案（国服/国际服/日服）、BanG Dream！少女乐团派对、BanG Dream！OurNotes（日服/国际服）、物华弥新、战双帕弥什、卡厄斯梦境、雪松、嘟嘟脸恶作剧、闪耀！优俊少女、赛马娘（日服/国际服）、女神异闻录：夜幕魅影、异环、少女前线2：追放、Fate/Grand Order、初音未来：缤纷舞台、星塔旅人、重返未来：1999。

主要功能：
· 一排看完当期卡池与活动，带剩余时间倒计时
· 悬停查看完整池名、UP 角色与活动时间明细
· 设置页可开关每一项是否展示、调整条目顺序、删除与恢复条目
· 卡池来源与活动来源可以分别切换（部分游戏提供多个社区来源可选）
· 可设置刷新频率（默认按天），避免频繁访问来源站
· 内置解析器自检：某个来源解析异常时能看出是哪一个

数据来源为各游戏官方公告页与社区 Wiki（Bwiki / PRTS / FZ Wiki / GameKee / Bestdori 等）。所有请求由你的浏览器直接发往这些来源站；本扩展不收集、不上传任何个人数据，不含统计与广告代码，也不注入或修改任何网页。
```

## 四、隐私页（Partner Center 的「隐私」页）

### 4.1 单一用途说明（Single purpose）

```
本扩展的单一用途是：让用户不必逐个打开各游戏官网，就能在一处查看多款二次元手游「当前正在进行的卡池与活动」及其起止时间。
```

### 4.2 权限理由（Permission justification）

**`storage`：**

```
仅用于在用户本机保存两类信息：(1) 用户偏好设置——哪些条目需要展示、条目顺序、卡池/活动来源的选择、刷新频率，以及用户手动填写的自定义来源地址；(2) 最近一次成功抓取的结果缓存，用于在来源站限流或网络异常时显示上次数据。这些数据只写入 chrome.storage.local，不同步、不上传，也不包含任何个人身份信息。
```

**主机访问权限（host_permissions，共 49 个域名）：**

```
本扩展的功能是抓取各游戏官方公告页与社区 Wiki 上的公开活动/卡池信息，因此需要访问这些来源站。浏览器要求扩展在发起跨域请求前静态声明目标域名，所以这些域名逐个列在 manifest 中。

关键点：
1) 未申请 <all_urls>，也没有任何通配的全网权限，只声明了实际抓取用到的具体域名；
2) 这些域名对应的是原神、星穹铁道、绝区零、明日方舟、蔚蓝档案、赛马娘、Fate/Grand Order 等游戏的官方公告页与社区 Wiki（Bwiki / PRTS / FZ Wiki / GameKee / Bestdori 等）；
3) 请求仅用于读取公开页面内容，不发送任何用户数据；扩展不包含 content script，也不会读取或修改用户正在浏览的网页。
```

### 4.3 是否使用远程代码

选 **「否，我没有使用远程代码」**。

依据：扩展为 Manifest V3，全部逻辑（含抓取核心 `gacha-calendar-core`）已在构建时内联进扩展包，
运行时不加载、不执行任何外部脚本，也没有 `eval` / `new Function`。
仓库内 `npm run verify` 有一项静态检查专门守这条（扫描 `background.js` / `popup.js` / `options.js`）。

### 4.6 认证测试说明（Certification notes）

```
本扩展无需登录、无需账号即可完整测试，启动后没有账号门槛。

测试步骤：
1. 安装后在工具栏点「二游日历」图标，面板会立即显示界面，并自动抓取一轮（约 5～15 秒）。
2. 每款游戏显示两行：当期卡池（含 UP 角色）与当期活动，右侧是剩余时间倒计时。
3. 鼠标悬停在卡池/活动文字上，会显示完整池名、UP 角色与时间原文。
4. 点面板右上角齿轮打开设置页，可开关每一款是否展示、调整顺序、删除与恢复条目、切换抓取来源。
   设置页最下方的「开始自检」会对每个来源各跑一次并报告结果。

可能需要知悉：
· 部分来源站有访问频率限制。若短时间内反复刷新，Bwiki 会返回 HTTP 567，面板会标注该来源「失败」
  并在该列沿用上一次成功的数据。这不是扩展缺陷，间隔一段时间即自行恢复。
· 少数游戏在当期尚未发布新卡池/活动时，会显示「未公布」或「无匹配」，属正常显示。
· 扩展不采集任何数据、不上传任何内容，也不包含 content script，因此不会修改任何网页。
```
