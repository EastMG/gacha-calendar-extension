## 二、说明（每种语言必填，250 ~ 10000 字符）

当前字数：880 字符（下限 250，上限 10000）。

```
「二游日历」把 28 款二次元手游当前正在进行的卡池与活动排期，收在一处看。

点浏览器工具栏图标即可弹出日程面板（520×600）：
· 顶部是「近期卡片」——按紧迫度显示最紧急的那一条（图标、剩余天数、档期与进度环），旁边列出接下来三项；也可在设置里切换成「近期列表」逐条浏览。
· 下方是日程表，每款游戏两行：第一行当期卡池（外显 UP 角色）、第二行当期活动，各自带起止时间、「还剩 X 天 X 小时」倒计时与一根 14 天进度条。
· 鼠标悬停在卡池/活动文字上，可查看完整池名、UP 角色列表与时间原文。

覆盖 28 款：原神、崩坏：星穹铁道、绝区零、崩坏3、鸣潮、明日方舟、明日方舟：终末地、蔚蓝档案（国服/国际服/日服）、BanG Dream！少女乐团派对、BanG Dream！OurNotes（日服/国际服）、物华弥新、战双帕弥什、卡厄斯梦境、雪松、嘟嘟脸恶作剧、闪耀！优俊少女、赛马娘（日服/国际服）、女神异闻录：夜幕魅影、异环、少女前线2：追放、Fate/Grand Order、初音未来：缤纷舞台、星塔旅人、重返未来：1999。

主要功能：
· 顶部「近期卡片 / 近期列表」二选一，按紧迫度排序
· 每款游戏两行（卡池 / 活动），带 14 天进度条与剩余倒计时
· 悬停查看完整池名、UP 角色与活动时间明细
· 设置页可为每个条目自定义强调色（影响进度条与卡片配色），可一键恢复默认
· 设置页可开关每一项是否展示、调整条目顺序、删除与恢复条目
· 卡池来源与活动来源可以分别切换（部分游戏提供多个社区来源可选）
· 可设置刷新频率（默认按天），避免频繁访问来源站
· 抓取失败时在常驻底栏提示是哪个来源、什么原因，点刷新图标即重试
· 内置解析器自检：某个来源解析异常时能看出是哪一个

数据来源为各游戏官方公告页与社区 Wiki（Bwiki / PRTS / FZ Wiki / GameKee 等）。所有请求由你的浏览器直接发往这些来源站；本扩展不收集、不上传任何个人数据，不含统计与广告代码，也不注入或修改任何网页。
```

## 四、隐私页（Partner Center 的「隐私」页）

### 4.1 单一用途说明（Single purpose）

```
本扩展的单一用途是：让用户不必逐个打开各游戏官网，就能在一处查看多款二次元手游「当前正在进行的卡池与活动」及其起止时间。
```

### 4.2 权限理由（Permission justification）

**`storage`：**

```
仅用于在用户本机保存两类信息：(1) 用户偏好设置——哪些条目需要展示、条目顺序、卡池/活动来源的选择、刷新频率，以及用户手动填写的自定义来源地址；(2) 最近一次成功抓取的结果缓存，用于在来源站限流或网络异常时显示上次数据。这些数据只写入 chrome.storage.local，不同步、不上传，也不包含任何个人身份信息。
```

**`declarativeNetRequestWithHostAccess`：**

```
仅用于给一处来源补 Referer 请求头。GameKee（蔚蓝档案）的内容数据放在一个 CDN 子域上，该 CDN 会校验 Referer，
而浏览器的 fetch 不允许页面/扩展自行设置 Referer。为此用 declarativeNetRequest 的 modifyHeaders 规则，
在请求发出前补上 `Referer: https://www.gamekee.com/`。

关键点：
1) 规则只匹配 api-cdn.gamekee.com（已授权的域名），不拦截、不修改其它任何网站的请求；
2) 只改请求头，不读取、不上传任何数据，不涉及响应内容；
3) 未申请 `declarativeNetRequest`（可拦截全站请求的那个权限），只用 withHostAccess 变体。
```

**主机访问权限（host_permissions，共 49 条）：**

```
本扩展的功能是抓取各游戏官方公告页与社区 Wiki 上的公开活动/卡池信息，因此需要访问这些来源站。浏览器要求扩展在发起跨域请求前静态声明目标域名，所以这些域名逐个列在 manifest 中。

关键点：
1) 未申请 <all_urls>，也没有任何 "所有网站" 的权限。49 条里 47 条是具体域名，另有 2 条与 GameKee 同域：
   https://gamekee.com/* 与 https://*.gamekee.com/*。后者是**子域通配**——因为 GameKee 的内容 CDN 地址
   是由接口响应里的 content_cdn 字段给出的（实测指向 api-cdn.gamekee.com），页面里并不固定出现，
   无法预先逐个列成具体域名，只能按域授权；除此之外没有任何通配权限；
2) 这些域名对应的是原神、星穹铁道、绝区零、明日方舟、蔚蓝档案、赛马娘、Fate/Grand Order 等游戏的官方公告页与社区 Wiki（Bwiki / PRTS / FZ Wiki / GameKee 等），另有少数用于加载游戏图标的静态资源域名；
3) 请求仅用于读取公开页面内容，不发送任何用户数据；扩展不包含 content script，也不会读取或修改用户正在浏览的网页。
```
