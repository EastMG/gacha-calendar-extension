二游日历 · 隐私政策

适用于浏览器扩展「二游日历」（Microsoft Edge / Google Chrome）。最后更新：2026-10-05

一句话总结：本扩展不收集、不上传、不共享你的任何个人数据。 它没有账号系统、没有开发者服务器、不含统计分析或广告代码，也不会注入或修改任何网页。

1. 我们收集哪些数据

不收集任何个人数据。具体而言，本扩展不会收集、记录或传输：

  • 姓名、邮箱、电话等身份信息（本扩展没有注册或登录功能）
  • 浏览历史、访问过的网页、点击行为
  • 设备标识符、广告标识符、位置信息
  • 你输入的任何自定义内容（见第 3 节，它们只保存在你自己的浏览器里）

2. 数据会离开你的浏览器吗

会，但只发往游戏信息来源站本身，不发给开发者。本扩展的功能是抓取各游戏官方公告页与社区 Wiki（如 Bwiki、PRTS、FZ Wiki、GameKee、Bestdori 等）上的公开活动/卡池信息。为此，你的浏览器会直接 向这些站点发起 HTTPS 请求。

这些请求与你在浏览器里直接打开该网站没有本质区别：请求头中带有标准的浏览器 User-Agent 与来源站的 Referer，但不包含任何由本扩展生成的用户标识， 也不包含你的浏览历史或本扩展的设置。开发者不运营任何接收这些请求的服务器，因此开发者无法看到 这些请求的内容或你的使用情况。

这些来源站对这些请求的处理受各自网站的隐私政策约束，与本政策无关。

3. 保存在你本地的数据

为了让它正常工作，本扩展使用浏览器提供的 chrome.storage.local 在本机保存两类信息。 这些数据仅存储在你的设备上，不会同步、不会上传：

  • 偏好设置：哪些游戏条目需要展示、条目顺序、卡池/活动来源的选择、刷新频率，以及你手动填写的自定义来源地址（如有）。
  • 抓取结果缓存：最近一次成功抓取到的卡池与活动内容，用于在网络异常或来源站限流时显示上次的数据。

卸载扩展或在浏览器中清除扩展数据，即可删除上述全部信息。

4. 权限用途说明

  • storage：仅用于在本机保存第 3 节所述的偏好设置与缓存。
  • 主机访问权限（host_permissions）：本扩展在清单中逐个列出了它所访问的 游戏信息来源域名，没有申请 <all_urls> 或任何通配的全网访问权限。 浏览器要求扩展在发起跨域请求前静态声明目标域名，因此这些声明是抓取功能的必要前提。

本扩展不包含内容脚本（content script），因此不会读取或修改你正在浏览的任何网页内容； 也不使用 declarativeNetRequest 等网络拦截能力。

5. 数据共享与出售

不共享、不出售、不转让任何数据 —— 因为我们根本不收集数据。

6. 儿童隐私

本扩展不收集任何用户数据，因此不涉及儿童个人信息的收集与处理。

7. 政策变更

若本政策发生变更，我们会更新本页面顶部的"最后更新"日期。由于本扩展不收集数据，预期不会出现实质性的政策变化。
